# Task 5 问题解决思路：字符轮廓检测

## 1. 任务要求

确定图像中字符的 outline(s)，并把轮廓检测结果展示出来。原文用复数
outline(s)，因此除了外轮廓，还要处理有封闭孔洞的字符（D、4、8、0、A）的
内轮廓。

## 2. 输入

`task_4/outputs/task4_binary.png`（899×148，Task 4 选定的二值图）。
用 connected-component labelling 保留面积 ≥300 px 的 10 个字符分量，去掉
116 个噪声斑点。

## 3. 方法（全部在 `common.py` 中自实现）

### 3.1 Moore-neighbor contour following（外轮廓）

1. 从分量**最左上**的前景像素 b0 出发，backtrace 像素 c0 为其西侧背景；
2. 从 c 之后的顺时针方向开始，依次检查当前像素 b 的 8 邻域，找到第一个
   前景像素作为下一个边界点 b'，并把检查顺序中 b' 前一个邻域作为新的
   backtrace 像素 c'；
3. 用 Jacob 停止准则（以相同方向重新进入起点）闭合轮廓。

轮廓按顺时针方向输出，可直接编码为 8 方向 Freeman chain code：
`0=E, 1=NE, 2=N, 3=NW, 4=W, 5=SW, 6=S, 7=SE`。

### 3.2 内轮廓（孔洞）

把分量取反后做连通域标记，不与图像边界接触的背景区域就是孔洞；对每个
孔洞再用同一个 Moore follower 追踪，得到有序内轮廓。

### 3.3 坐标恢复与验证

每个字符先按包围框裁剪并补 1 px 边框，再追踪。追踪输出是裁剪图坐标，
在叠加、绘制掩膜或导出前必须恢复到 Task 3 子图坐标：
`(row - pad + y0, col - pad + x0)`。外轮廓和内轮廓都使用相同的变换。
运行时检查轮廓在相应字符包围框内、外轮廓像素属于该字符前景、孔洞轮廓
像素属于背景，以及非单像素轮廓以 8 邻接步闭合，避免局部坐标误用于整图。

## 4. 结果要点（见 `task5_outlines.json`）

| 字符 | 外轮廓长 | 孔洞 |
|---|---|---|
| H | 619 | 0 |
| D | 379 | 1 |
| 4 | 368 | 1 |
| 4 | 340 | 1 |
| 7 | 408 | 0 |
| 8 | 515 | 1（本应 2） |
| 0 | 329 | 3（1、2 px 伪孔 + 主孔） |
| A | 364 | 1 |
| 0 | 332 | 2（229 + 3 px 伪孔） |
| 0 | 325 | 1 |

外轮廓总长 3979 px。异常说明：

- `8` 只检出 1 个孔：二值化把下环内壁断开，下环内部与背景连通，只剩上环
  封闭；
- 两个 `0` 出现 1–3 px 的伪孔：笔画断裂造成的极小封闭背景区。

结论：十个保留分量仍有可追踪的闭合外轮廓，但轮廓表示的是选定二值掩膜，
并不意味着笔画缺陷没有改变字符形状。`8` 的下环断开已改变拓扑，内轮廓
数量更依赖二值化质量；Task 6 的面积过滤可去掉小前景噪声分量，但不会
修复这些内部孔洞或断开的环。

## 5. 输出文件（`task_5/outputs/`）

- `task5_outlines.png`：灰度子图上叠加轮廓（实线外轮廓、虚线孔洞，每字符
  一色）；
- `task5_outline_mask.png`：纯边界像素图；
- `task5_example_trace.png`：第二个 `4` 放大，标出起点与追踪方向；
- `task5_outlines.json`：每字符 bbox、外轮廓长、孔洞数/长度、完整外/内轮廓
  坐标 (`outer_trace` / `hole_traces`)、完整链码及其起点。旧的
  `chain_code_prefix` 与 `chain_code_length` 等统计字段保持兼容。

JSON 中的轮廓和链码起点统一使用 Task 3 子图坐标，顺序为 `(row, col)`。
链码包含最后回到起点的一步；解码时先放入起点，再按每个方向增加一个点，
最后按对应的 `outer_boundary_length` / `hole_boundary_lengths` 截取，
即可与保存的有序坐标一致（极小孔洞的有序坐标可能已含重复终点）。
单像素孔洞的链码为空，用其起点即可还原。利用所有完整坐标或解码后的
完整链码，可以重建与 `task5_outline_mask.png` 完全一致的像素掩膜。

## 6. 风险与注意

- Moore 追踪默认 8 连通，遇到 1 px 细笔画时可能切角或振荡；本项目笔画
  较粗（约 8–20 px）且只追踪大分量，实测全部正常闭合。
- 内轮廓数量依赖二值化质量，报告中必须区分“真实孔洞”与“断裂伪孔”，不能
  把孔洞数直接当形状特征。
