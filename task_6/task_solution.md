# Task 6 问题解决思路：字符分割与标记

## 1. 任务要求

对图像做 segmentation，使不同字符尽可能清楚地分离，并分别标记
(label)；展示分割与标记的中间结果，讨论粘连字符、断裂字符、噪声区域和
误分割。

## 2. 输入

`task_4/outputs/task4_binary.png`（899×148）。二值化时已经通过 41×41 局部
自适应阈值让十个字符各自成为独立前景区域，因此本任务的核心是“连通域标记
+ 噪声过滤 + 排序”。

## 3. 方法（`common.py` 自实现 two-pass union-find）

1. **连通域标记**：第一遍扫描，每个前景像素取“已访问的 8 邻域中最小的
   label”，并用 union-find 合并等价类；第二遍统一为根 label。
2. **面积过滤去噪**：保留面积 ≥300 px 的分量。Task 4 实测最大噪声分量
   224 px，最小字符 2719 px，阈值取在两者之间的宽空隙里，鲁棒。
3. **从左到右排序**：按各分量的最左列排序，得到 1–10 的阅读顺序标签。

## 4. 结果要点

- 恰好得到 **10 个字符分量**，从左到右对应 `H D 4 4 7 8 0 A 0 0`；
- 各分量 bbox 宽 80–88 px、高 114–131 px，尺寸均匀；
- 相邻字符 bbox 间隔仅 `9, 4, 10, 10, 2, 3, 3, 2, 6` px，非常紧。

### 粘连 / 断裂分析

- **粘连**：若对 Task 4 的全局 Otsu 二值图做同样分割，只会得到 **7 组**
  ——`D+4`、`8+0`、`0+0` 粘连（`task6_segmentation_comparison.png` 对比图）。
  这说明单纯投影切分不可靠，也说明 Task 4 选自适应阈值对分割是决定性的。
- **断裂**：`8` 下环内壁有缺口，但外轮廓仍连通，标记后仍是单一分量；
  两个 `0` 的笔画内部有 1–3 px 伪孔，不影响分量级分割。
- **噪声**：116 个 ≤224 px 的纹理斑点全部被面积准则清除。

## 5. 输出文件（`task_6/outputs/`）

- `task6_labeled.png`：灰度图上标记 1–10；
- `task6_boxes.png`：各字符 bounding box；
- `task6_crops.png`：10 个字符 crop 网格；
- `task6_cleaned_binary.png`：去噪后的二值图；
- `task6_segmentation_comparison.png`：Otsu(7 组) vs 自适应(10 组)；
- `task6_components.csv` / `.json`：每字符 order、bbox、面积、质心、crop 路径；
- `chars/char_01..10_gray.png` / `_bin.png`：**供 Task 7 分类用的字符 crop**。

## 6. 风险与注意

- 面积阈值 300 依赖“字符远大于噪声”这一事实；若换图后噪声变大，需重新
  检查两个群体的间隔。
- 相邻字符间隔最小只有 2 px，若二值化参数变化导致再次粘连，应优先回头
  调整 Task 4 的阈值/偏移，而不是在本任务里加切分启发式。
- 报告中的 label 是 1–10 的阅读顺序；真正的字符类别映射
  (`H D 4 4 7 8 0 A 0 0`) 是已知 ground truth，Task 7 用它评估分类器。
