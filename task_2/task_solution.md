# Task 2 问题解决思路：均值滤波与不同尺寸比较

## 1. 任务要求

1. 自行实现并应用一个 5×5 averaging filter（均值滤波）；
2. 继续尝试不同尺寸的滤波器；
3. 比较各平滑结果并评论。

需要同时考虑去噪能力与字符边缘/细节损失，不能只展示单一 5×5 结果。

## 2. 输入

- 使用 Task 1 选定的增强灰度图 `task_1/outputs/task1_percentile_stretch_p02_p98.png`（990×367），保证后续 pipeline 一致。
- 测试尺寸：3×3、5×5（必做）、7×7、11×11、15×15，全部为奇数边长。

## 3. 实现（NumPy 从零实现，`common.box_filter`）

均值滤波：

```text
out(x,y) = (1/s^2) * sum_{i=-r..r, j=-r..r} in(x+i, y+j),  r=(s-1)/2
```

- 箱式核可分离，用**积分图（summed-area table）**把复杂度从 O(h·w·s²) 降到 O(h·w)，与核尺寸无关；
- 边界用边缘复制（edge replication）填充，不做零填充，避免边界变暗。

## 4. 评价指标（同一批固定 patch，保证可比）

- **背景标准差**：5 个固定无字符背景 patch 的合并标准差，越小代表纹理/斑点噪声抑制越强；
- **前景梯度**：5 个固定字符笔画 patch 的中心差分梯度幅值均值，越小代表笔画边缘越模糊；
- **PSNR**：相对未滤波增强图的峰值信噪比，衡量整图变化程度。

实测结果（`task2_metrics.csv`）：

| 滤波 | 背景 std | 前景梯度 | PSNR (dB) |
|---|---|---|---|
| 无 | 33.42 | 20.18 | ∞ |
| 3×3 | 29.56 | 14.75 | 28.50 |
| 5×5 | 26.46 | 11.00 | 24.03 |
| 7×7 | 24.09 | 9.44 | 21.95 |
| 11×11 | 19.91 | 7.86 | 20.17 |
| 15×15 | 16.36 | 6.75 | 18.90 |

## 5. 结论

- 存在单调 trade-off：核越大背景噪声越少，但笔画边缘越糊。
- 3×3 太弱（噪声只降 11.5%）；15×15 把 51.0% 噪声去掉的同时抹掉 66.5% 边缘锐度，细笔画有断裂/粘连风险。
- **选 5×5**：噪声降 20.8%，保留 54.5% 边缘，PSNR=24.03 dB，是当前图像的最佳折中；Task 3/4 复用该 5×5 平滑。

## 6. 输出文件（`task_2/outputs/`）

- `task2_box_3x3.png` … `task2_box_15x15.png`：各尺寸滤波结果；
- `task2_comparison.png`：增强原图 + 五种尺寸对比；
- `task2_zoom.png`：底部文字行 `HD4` 区域放大，直观展示笔画模糊；
- `task2_metrics.csv`：指标表。

## 7. 风险与注意

- 若更换测试图，固定 patch 坐标需重新标定；核尺寸结论（5×5 折中）应重新验证。
- 这里只比较均值滤波；中值滤波（去椒盐更好、边缘保持更好）未在本任务范围内实现。
